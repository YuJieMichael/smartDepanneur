# 发错群了 原型 v0.1

## 假设

「手一滑把消息发错群」的社死瞬间本身就好笑，而且天然就是能截图转发的内容。
玩家会在多线消息的压力下真的发错，看到对方反应时会笑，并且想把结算页的「今日社死精选」截图发给朋友。

选这个点子的标准：一张截图或 3 秒视频就能让人笑出来或想玩（参考 2026 年 TikTok 爆款 MECCHA CHAMELEON 的规律）。
吸取前两个原型（星图卡组、地牢点评网，均已 KILL）的教训：核心动作要马上有回报；规则少；有反馈；先定放弃标准。

## 怎么运行

打开 `wrong-chat.html` 的 Artifact 链接。电脑上玩，键盘更顺手。

进行中（in-progress）。

## 规则

| 项目 | 设定 |
|---|---|
| 一天 | 3 分钟，从 9:00 到 18:00；消息越到后面来得越快 |
| 聊天 | 项目组（王总、小李、HR 张姐）、相亲相爱一家人（妈、爸、二姨、三舅）、宝（对象）、废物联盟（阿杰、胖子、小美） |
| 回复 | 每条要回的消息会生成一张回复卡片。卡片上**不写是回谁的**，点一下（或按 1–8）就发进**当前打开**的聊天 |
| 切换 | 点左边列表或按 Q W E R；其他聊天来消息时顶部会弹出通知，点通知直接跳过去 |
| 回对 | 关系 +8，对方有时回一句 |
| 没回 | 超时后关系 −14，对方追问「人呢？」 |
| 发错 | 1.6–3 秒后对方「已读」，接着一连串反应，盖章「社死 +N」，关系下降。最危险的组合（比如把「我们老板就是个画饼大王」发进工作群）有专门写的反应 |
| 撤回 | 按 Z，一天 3 次。「已读」之前撤回没人看到；之后撤回会被说「我看到了」 |
| 结束 | 撑到 18:00 下班；任何一段关系掉到 0 就提前结束（比如「王总：你明天不用来了」） |
| 结算 | 社死称号 + 「今日社死精选」：每次发错的现场，做成聊天截图的样子 |

## 放弃标准

**玩 5 分钟，如果没有一次发错让你笑出来或想截图，就 KILL。**

## 试玩时观察什么

| 观察项 | 怎么判断 |
|---|---|
| 会不会真的发错（而不是故意） | 记录里「✗」的次数，问试玩者是不是手滑 |
| 发错时会不会笑 | 直接看反应 |
| 想不想截结算页 | 问试玩者，或看是否主动截图 |
| 会不会故意发错找乐子 | 如果会，说明反应文案是卖点，可以考虑加「故意社死」玩法 |
| 想不想再过一天 | 是否主动点「再过一天」 |
