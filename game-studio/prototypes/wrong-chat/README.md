# 发错群了 原型 v0.3

## 假设

「手一滑把消息发错群」的社死瞬间本身就好笑，而且天然就是能截图转发的内容。
玩家会在多线消息的压力下真的发错，看到对方反应时会笑，并且想把结算页的「今日社死精选」截图发给朋友。

选这个点子的标准：一张截图或 3 秒视频就能让人笑出来或想玩（参考 2026 年 TikTok 爆款 MECCHA CHAMELEON 的规律）。
吸取前两个原型（星图卡组、地牢点评网，均已 KILL）的教训：核心动作要马上有回报；规则少；有反馈；先定放弃标准。

## 怎么运行

打开 `wrong-chat.html` 的 Artifact 链接。电脑上玩，键盘更顺手。

## 状态

进行中（in-progress）。

## 规则

| 项目 | 设定 |
|---|---|
| 一天 | 3 分钟，从 9:00 到 18:00；消息越到后面来得越快 |
| 聊天 | 项目组（王总、小李、HR 张姐）、相亲相爱一家人（妈、爸、二姨、三舅）、宝（对象）、废物联盟（阿杰、胖子、小美） |
| 回复 | 每条要回的消息会生成一张回复卡片。卡片上**不写是回谁的**，点一下（或按 1–8）就发进**当前打开**的聊天 |
| 切换 | 点左边列表或按 Q W E R；其他聊天来消息时顶部会弹出通知，点通知直接跳过去 |
| 回对 | 关系 +8，对方有时回一句 |
| 没回 | 超时后关系 −14，对方追问「人呢？」 |
| 发错 | 1.6–3 秒后对方「已读」，接着一连串反应，盖章「社死 +N」，关系下降。最危险的组合（比如把「我们老板就是个画饼大王」发进工作群）有专门写的反应 |
| 撤回 | 按 Z，一天 3 次。「已读」之前撤回没人看到；之后撤回会被说「我看到了」 |
| 结束 | 撑到 18:00 下班；任何一段关系掉到 0 就提前结束（比如「王总：你明天不用来了」） |
| 结算 | 社死称号 + 「今日社死精选」：每次发错的现场，做成聊天截图的样子 |

## 放弃标准

**玩 5 分钟，如果没有一次发错让你笑出来或想截图，就 KILL。**

## 试玩时观察什么

| 观察项 | 怎么判断 |
|---|---|
| 会不会真的发错（而不是故意） | 记录里「✗」的次数，问试玩者是不是手滑 |
| 发错时会不会笑 | 直接看反应 |
| 想不想截结算页 | 问试玩者，或看是否主动截图 |
| 会不会故意发错找乐子 | 如果会，说明反应文案是卖点，可以考虑加「故意社死」玩法 |
| 想不想再过一天 | 是否主动点「再过一天」 |

## 发现

### 试玩 1（v0.1，桌面端）

- 回对 15 条，**发错只有 1 条**（社死 +1），**没回 16 条**。15:42 因家族群关系掉到 0 提前结束。
- 问题：玩家总是先打开聊天、看到问题、再挑对应卡片，这个流程几乎不会发错。
  压力全变成了「回不过来」，没有测到「发错群」这个核心时刻，放弃标准无法判断。

### v0.2 改动（照着现实里发错群的方式）

- **加输入框**：点卡片后字会在输入框里打 1–2 秒，打完按 Enter 才发送。
- **切换聊天时输入框里的字不会消失**：打字的空档切去别的群看一眼，回来按 Enter 就可能发错。
- **降低「回不过来」的压力**：同时待回最多 5 条；回复时限 16–24 秒（原来 12–20）；消息间隔 2.4–6 秒（原来 1.6–5.2）；超时扣 10（原来 14）。
- 字打完时对方已经超时，发进对的聊天算「回晚了」，不加分也不扣分。

### 试玩 2（v0.2）

- 设计者反馈：**还行**。要求把四个方向都加上：第三批的其他点子、更多群和角色、故意社死玩法、更多反应和后果。

### v0.3 改动

**第三批点子变成工作日里的突发事件**
- 10:30 视频会议（16 秒小游戏）：← → 移动镜头，别让猫、室友、晾着的内衣、外卖小哥、敷面膜的妈入镜，脸还得留在镜头里；空格可关一次摄像头 3 秒。开会时聊天倒计时暂停。
- 12:40、16:10 老板巡视：3 秒内必须切到项目组，否则王总当面点评你屏幕上的聊天。
- 14:20 广场舞接龙：家族群接龙「4. 我（家属）」，发错群会让别的群也开始接龙。
- 17:20 下班挤地铁：手机每 4–6 秒被挤得随机切换聊天。

**更多群和角色**
- 高三（2）班（班长、学霸）、小陈（妈介绍的相亲对象）。宝和小陈之间发错会更严重。
- 小陈的关系掉到 0 不会结束游戏，而是「被小陈删了」，妈在家族群里追问，家人关系 −20。
- 一天从 3 分钟延长到 4 分钟；同时待回最多 6 条。

**故意社死玩法**
- 开局可选「正常上班」或「故意社死」（不会被开除、不会被分手）。
- 社死图鉴：79 种反应（每句话 × 每个群的通用反应，加上专门写的组合）。发现过的会记在这个浏览器里，结算页显示新发现。

**更多反应和后果**
- 发错进项目组（社死 ≥ 2）：王总私聊叫你去办公室，6 秒内不能打字、不能发消息。
- 社死 ≥ 4 的群聊发错：被移出群聊 25 秒，再被拉回来。
- 社死 ≥ 3：60% 概率截图流传到另一个群，再 +1。
- 结算页每张社死截图下面会写出后续后果。
