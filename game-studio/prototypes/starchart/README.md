# 星图卡组原型 v0.1

## 假设

同一张星图在多场战斗之间持续存在，早先的连接会改变后续的机会和代价。
这种「持续改造星图」能产生足够多的策略选择：到了第五场战斗，玩家仍会重新考虑怎么连，
而不是收敛成同一种布局，或者机械地重复激活。

## 怎么运行

- 打开 `starchart.html` 的 Artifact 链接直接试玩（手机和电脑都可以）。
- 本地打开 `starchart.html` 也能玩，但缺少发布时自动加上的页面外壳，显示可能略有差别。

## 状态

已结束（concluded）。结论：**KILL**（2026-10-15）。

## 这一版的规则

| 项目 | 设定 | 为什么 |
|---|---|---|
| 胜负压力 | 打赢敌人；敌人每回合预告意图 | 只优化一件事：活下来并击败它，不混用 Balatro 式计分 |
| 星图 | 10 颗固定位置的星（角亢氐房心尾箕 + 斗牛女） | 固定布局，方便比较不同人的打法 |
| 操作 | 连线、剪线、移动星、激活结构，共用每回合 4 行动点 | 测试拆线和改线是否值得 |
| 约束 | 每颗星最多连 2 条线；线不能交叉，也不能穿过别的星 | 「连线容量上限」：图画不满，旧结构会挡住新结构 |
| 图形 | 链（攻击，伤害 1+2+…+线数）、环（防御，格挡 = 星数 × 2） | 两种真正不同的用途；链首尾一连就变成环，开口还是闭合是核心取舍 |
| 激活 | 每次 1 点；每颗星每回合只能参与一次激活 | 旧结构仍要花能量才生效，避免「建一次、白嫖到底」 |
| 确定性 | 没有任何随机；伤害、目标、效果都确定 | 「不靠运气」只承诺：操作结果确定、当前意图清楚、失败原因可理解 |
| 可读性 | 悬停显示操作前后结构变化和敌人目标变化；本回合内可撤销 | 控制「完全信息」的计算负担 |
| 三场战斗 | 天狗吞掉最大结构的中间星；孛星剪断最长的线；荧惑的灼甲让少于 4 条线的链无效，并封锁心宿一带 | 不同敌人改变连线需求，逼玩家改造已有星图 |
| 成长 | 每胜一场三选一：增加节点（新星）、修改节点（亮星或坚星）、改造连接（金线或解缆） | 奖励的价值取决于当前星图 |

敌人的目标（吞哪颗星、剪哪条线）会随你的星图实时变化，并在图上用红色标出。
玩家可以主动改造星图，让敌人打到无关紧要的地方。

## 实验设置

页面底部「实验设置」可以切换，切换后从第一战重开：

- 每回合行动点：3、4（默认）、5
- 激活结构消耗：0、1（默认）、2
- 链伤害公式：累加（默认）或线性
- 环每颗星的格挡：2（默认）或 3
- 公开敌人后续意图：关（默认）或开，用来对照「完整公开未来行动」的效果

## 试玩时观察什么

每位试玩者结束后，点「复制试玩记录」，把记录贴进下面的表格或单独的文件。

| 观察项 | 怎么判断 | 记录 |
|---|---|---|
| 结算前能否说出效果 | 激活或结束回合前，请试玩者说出会发生什么，再对照结果 | |
| 是否主动拆旧结构 | 记录里剪线、移动的次数；问他为什么拆 | |
| 同一布局是否有不同的合理打法 | 比较不同试玩者第一战的连线 | |
| 后半局是否仍有新决策 | 第三战是否还在剪线、移动，还是只连线加激活 | |
| 是否想再试一种构筑 | 结算后是否主动点「再试一种构筑」 | |

理想中的一回合是一个跨回合的取舍：现在闭合一个小环挡住攻击；
或者保留这两颗星、承受一些伤害，为下一回合的大链铺路。

## 怎么根据结果决定下一步

- **换几张图仍然只靠同一种布局取胜：** 先改收益和约束（链公式、激活消耗、容量上限），不加内容。
- **玩家会为了不同敌人主动改造已有星图，并且想再试另一种结构：** 有充分理由继续扩充内容
  （更多敌人、第三种图形「分支」、更多星官）。
- **玩家说不清操作会产生什么效果：** 先改可读性（预览、高亮、规则），再看策略深度。

## 发现

### 试玩 1（v0.1，第一战未打完）

记录：4 回合，连线 11、移动 1、剪线 0、**激活 0**，造成 0 伤害，承受 25。

1. **激活机制没被发现，这是阻断性问题。** 第 2 回合结束时，星图上有一条 8 线的长链
   （箕尾心房氐女斗牛角，值 36 伤害，天狗只有 32 血），但行动点全花在连线上，没能激活。
   第 4 回合有 4 点行动点、两个现成的环（共 18 格挡，敌人只打 6），仍然「无操作」直接结束。
   v0.1 把激活按钮放在侧栏，手机上会排到规则下面，很可能根本看不到。
   在这个问题解决之前，策略深度的结论都不可信。
2. **跨回合铺路自然出现了。** 玩家先花两回合铺长链，说明「这回合建、下回合用」的节奏是成立的。
3. **天狗的吞星正好吃掉长链的中点。** 8 线链被拆成两段 3 线链，价值从 36 降到 6+6。
   需要确认玩家结束第 2 回合前，是否看到了氐上的「将被吞」标记。
4. **玩家倾向闭合图形。** 两段残链都被补成了环（5 星环、4 星环），全场没有攻击来源。
   可能是「画星座」的直觉偏向闭合形状，也可能是连续掉血后想防御。值得在后续试玩中继续观察。

### v0.2 改动（只改可读性，不改规则）

- 「结构」卡片移到星图正下方，手机上也紧挨着棋盘。
- 地图上可激活的结构标签会亮起（实心色块加 ▸），直接点标签即可激活。
- 还有可激活结构时按「结束回合」，会先列出这些结构，需要再点一次「确认结束」。
- 连线、剪线、移动改变了敌人目标时，状态栏会提示新的目标。
- 试玩记录每回合会写明剩余行动点，以及没有激活的可用结构。

### 试玩 2（v0.2，桌面端）与结论

设计者本人在电脑上试玩后的判断：不好玩。决定放弃这个方向（KILL）。

原因判断：
- 核心动作（画线）没有即时回报，回报藏在单独的「激活」步骤里，主操作像在记账。
- 规则多（容量上限、不能交叉、行动点、激活、本回合已激活）而回报少。
- 灰盒里没有任何反馈（伤害数字、敌人反应、音效），打中和没打中感觉一样。

留给后续原型的教训：
1. 先验证「好玩的那一下」，再验证策略深度。核心动作本身必须有即时、可感知的回报。
2. 第一版规则越少越好，只保留产生核心张力所必需的规则。
3. 灰盒也要有最基本的反馈（数字、声音、屏幕反应），否则无法判断好不好玩。
