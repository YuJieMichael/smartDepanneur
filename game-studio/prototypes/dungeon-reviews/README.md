# 地牢点评网原型 v0.1

## 假设

「把地牢调到让冒险者差点死掉」这件事本身就好玩：
玩家看到下一位冒险者的血量和攻击后，会主动调整房间；看他闯关、读他的点评，会想再调一次、再放一个人进来。

这次吸取了星图卡组（已 KILL）的教训：

1. 核心动作要马上有回报：放人进去几秒内就能看完闯关过程，接着立刻弹出点评。
2. 规则少：6 个房间排成一列，评分只看「出来时剩多少血」。
3. 灰盒也要有反馈：弹出的伤害数字、房间震动、简单音效、好笑的点评文字。

## 怎么运行

打开 `dungeon-reviews.html` 的 Artifact 链接直接玩。电脑和手机都可以；按空格也能放人进来。

## 规则

| 项目 | 设定 |
|---|---|
| 地牢 | 6 个房间，冒险者从左往右依次经过 |
| 可以放的东西 | 史莱姆、骷髅兵、巨魔（怪物）；地刺（陷阱）；宝箱；泉水（回血） |
| 冒险者 | 新手、盗贼（会拆陷阱）、战士、法师、骑士、勇者；放进来之前就能看到血量和攻击 |
| 战斗 | 冒险者先出手，双方轮流攻击；每次伤害有 ±20% 的浮动，所以看的时候会紧张 |
| 星级 | 出来时剩 30% 以内的血得 5 星；30–60% 得 4 星；60–85% 得 3 星；85% 以上得 2 星；死在里面得 1 星（但钱包归你）；开到有钱的宝箱 +1 星，空宝箱 −1 星 |
| 经济 | 开局 50 金。门票是收入。怪物和陷阱买一次就一直在；宝箱每被打开一次要花 15 金补充；拆除退回一半 |
| 难度递进 | 近 5 条评价的平均分越高，来的冒险者越强，门票越贵 |
| 一季 | 15 位冒险者，按综合评分颁奖：年度最佳地牢（4.5 以上）、网红打卡地牢、街坊口碑地牢、差评如潮 |

## 试玩时观察什么

| 观察项 | 怎么判断 |
|---|---|
| 是否每位冒险者都去调整房间 | 试玩记录里，每一行的「布置」是否经常变化 |
| 看闯关时会不会紧张 | 「会不会死？」的时刻有没有让人屏住呼吸 |
| 点评会不会让人笑、想看下一条 | 直接问试玩者 |
| 打完一季后想不想再开一季 | 是否主动点「再开一季」 |
| 有没有一种布置能通吃所有冒险者 | 如果有，说明冒险者之间差别不够，需要加强 |
