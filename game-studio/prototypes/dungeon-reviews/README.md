# 地牢点评网原型 v0.3

## 假设

「把地牢调到让冒险者差点死掉」这件事本身就好玩：
玩家看到下一位冒险者的血量和攻击后，会主动调整房间；看他闯关、读他的点评，会想再调一次、再放一个人进来。

这次吸取了星图卡组（已 KILL）的教训：

1. 核心动作要马上有回报：放人进去几秒内就能看完闯关过程，接着立刻弹出点评。
2. 规则少：6 个房间排成一列，评分只看「出来时剩多少血」。
3. 灰盒也要有反馈：弹出的伤害数字、房间震动、简单音效、好笑的点评文字。

## 怎么运行

打开 `dungeon-reviews.html` 的 Artifact 链接直接玩。电脑和手机都可以；按空格也能放人进来。

## 状态

进行中（in-progress）。

## 规则

| 项目 | 设定 |
|---|---|
| 地牢 | 6 个房间，冒险者从左往右依次经过 |
| 可以放的东西 | 史莱姆、骷髅兵、巨魔（怪物）；地刺（陷阱）；宝箱；泉水（回血） |
| 冒险者 | 新手、盗贼（会拆陷阱）、战士、法师、骑士、勇者；放进来之前就能看到血量和攻击 |
| 战斗 | 冒险者先出手，双方轮流攻击；每次伤害有 ±20% 的浮动，所以看的时候会紧张 |
| 星级 | 出来时剩 30% 以内的血得 5 星；30–60% 得 4 星；60–85% 得 3 星；85% 以上得 2 星；死在里面得 1 星（但钱包归你）；开到有钱的宝箱 +1 星，空宝箱 −1 星 |
| 经济 | 开局 50 金。门票是收入。怪物和陷阱买一次就一直在；宝箱每被打开一次要花 15 金补充；拆除退回一半 |
| 难度递进 | 近 5 条评价的平均分越高，来的冒险者越强，门票越贵 |
| 一季 | 15 位冒险者，按综合评分颁奖：年度最佳地牢（4.5 以上）、网红打卡地牢、街坊口碑地牢、差评如潮 |

## 试玩时观察什么

| 观察项 | 怎么判断 |
|---|---|
| 是否每位冒险者都去调整房间 | 试玩记录里，每一行的「布置」是否经常变化 |
| 看闯关时会不会紧张 | 「会不会死？」的时刻有没有让人屏住呼吸 |
| 点评会不会让人笑、想看下一条 | 直接问试玩者 |
| 打完一季后想不想再开一季 | 是否主动点「再开一季」 |
| 有没有一种布置能通吃所有冒险者 | 如果有，说明冒险者之间差别不够，需要加强 |

## 发现

### 试玩 1（v0.1，桌面端）

- 设计者本人的判断：**好玩**。核心循环（看客人 → 调房间 → 看闯关 → 读点评）成立。
- 顾虑：地牢经营类竞品很多（Dungeon Keeper、Dungeons 系列、Legend of Keepers 等）。
  但主流同类的目标都是「杀死冒险者」，这里反过来：要让客人活着出来，还要拿好评。
  最接近的是正在开发的鬼屋经营类（Scream Operator、ScareZone）。
- 决定：把卖点从「地牢经营」移到「讽刺点评文化」，v0.2 验证这一点能不能让游戏更好笑、更有辨识度。

### v0.2 改动：点评网角色

- **探店博主**（第 3、9、14 位）：评价权重 ×3。
- **差评师**（第 6、12 位）：进门前要 20 金。给了，必定五星（死了也给）；不给，他的评价扣 2 星。
- **刷好评**：花 15 金买一条五星假评价。每条还挂着的假评价，都会让每次真实评价后的「平台核查」概率 +12%。
  被查到会删掉所有假评价，并挂上一条一星的平台公告。
- **挑剔顾客**：约一半普通客人带一个偏好，进门前可见：讨厌史莱姆、爱泡温泉、财迷、硬核玩家。

v0.2 要回答：这些角色是让你觉得「这个只有我们有」，还是只是「另一款地牢游戏」？

### 试玩 2（v0.2，桌面端，种子 1086446791）

- 前 8 位：布置一直在调，评分在 4–5 星。偏好真的改变了布置：遇到「讨厌史莱姆」把史莱姆换成了骷髅兵，
  遇到「爱泡温泉」加了泉水，两次都拿到五星。
- #8 之后布置再没变过，连死 7 位（包括两位博主，各算 3 条一星），加权平均跌到 2.67。
- 原因（设计者自述）：腻了；往低调难度要拆怪物、亏一半钱，嫌麻烦；死人还给钱包，金币在涨就随它去了。
- 差评师两次都给了钱（稳赚不赔，不算选择）；刷单一次没用（看到了，但当时没钱）。
- 设计问题：评分越低派来的客人越弱，按骑士调好的地牢会把他们全杀掉，形成死亡螺旋。

### v0.3 改动

- **房门开关**：不选工具时点房间，免费开门或关门，关着的房间客人直接走过。去掉了房间互换。
- **客人强弱不再跟评分挂钩**：按季内顺序逐渐出现更强的客人，但强弱始终混着来。
- **去掉「钱包归你」**；改为每位客人进门时，所有怪物发工资（史莱姆 1、骷髅兵 2、巨魔 4）。季末金币为负数就是「欠薪破产」。
- **给差评师的钱也算一条刷单**，会提高平台核查概率；被查时一起删除。
- **一季从 15 位缩短到 12 位**，特殊客人：博主第 3、7、11 位，差评师第 5、9 位。

v0.3 要回答：有了免费的房门，你会不会每位客人都调一下？12 位客人打完会不会想再开一季？
