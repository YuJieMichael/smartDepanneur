# 游戏点子池（与 SmartDepanneur 无关的新游戏）

这是进入 `/brainstorm` 之前的点子清单，用来挑方向，不是正式设计文档。
选定一个以后，在 `game-studio/` 目录里运行 `claude`，再执行
`/brainstorm <点子名>`，生成正式的 `design/gdd/game-concept.md`。

筛选标准：

- 一个人加 Claude 能在 2–3 个月内做出可玩版本
- 美术需求低，靠机制取胜（简单几何图形或像素美术就够）
- 核心规则能写成数据和公式，适合 AI 协作写代码和测试

---

## 推荐优先做的三个

### 1. 回放小队（Echo Squad）

- **一句话**：每一回合你只操作一个角色，下一回合前面所有回合的操作会被
  原样重放，你要和「过去的自己」配合打败 Boss。
- **核心循环**：观察关卡 → 录制角色 A → 录制角色 B，A 自动重放 →
  一共 4–5 个角色同时行动 → 胜利或修改某一轮重录。
- **亮点**：时间悖论式的协作解谜，每关都有很多种解法，适合做速通和分享录像。
- **规模**：小。2D 俯视视角，10–20 个关卡就成立。
- **难点**：重放必须完全确定性（固定帧步长、固定随机种子）。
- **引擎建议**：Godot 4（2D）。

### 2. 星图卡组（Starchart）

- **一句话**：Roguelike 卡组构筑，但你不是抽牌，而是在夜空里连线星星；
  连出来的星座形状决定这一回合的技能。
- **核心循环**：查看星空 → 连线组成星座（形状越复杂效果越强，但消耗回合）
  → 结算战斗 → 战后获得新星星或改写星座效果。
- **亮点**：「画形状」本身就是操作手感；星座图鉴有收集欲。
- **规模**：小到中。主要工作量在数值平衡，美术只要星点、连线和粒子。
- **难点**：形状识别要宽容，数值要用表格驱动，方便反复调整。
- **引擎建议**：Godot 4，或用 Phaser 3（你熟悉 TypeScript，可以直接做成网页游戏）。

### 3. 电梯之神（Lift Logic）

- **一句话**：你给一栋大楼的电梯写调度规则，用可视化积木或简化脚本，
  让早高峰的人群不要等疯。
- **核心循环**：读取本关客流 → 编写或修改规则 → 快进模拟 →
  看等待时间、能耗和投诉分 → 优化。
- **亮点**：编程解谜（类似 Zachtronics 系列），每关有排行榜，
  玩家会互相比较解法。
- **规模**：小。纯逻辑加简单 2D 楼体剖面。
- **难点**：规则语言要简单但够用；模拟必须可复现，排行榜才公平。
- **引擎建议**：网页（TypeScript + Phaser 或 Canvas）最合适，方便分享链接。

## 其他点子

### 4. 潮汐邮差（Tide Courier）

- 海边小镇每天潮水涨落都会改变地图，道路、栈桥和洞穴时有时无。
- 你在一天内送完所有信件，需要规划路线和等潮的时机。
- 回合制路径解谜，带轻度叙事：每封信都在讲镇上一段故事。

### 5. 地牢点评网（Dungeon Yelp）

- 你经营一座地牢，冒险者进来以后会留下星级评价。
- 太难了没人来，太简单了冒险者会抢光宝藏。
- 你要平衡难度、口碑和宝箱成本，目标是成为「年度最佳地牢」。
- 幽默向的模拟经营，评论文本可以由数据模板生成。

### 6. 回声潜行（Echolocate）

- 整个屏幕是黑的，只有你发出的声音（脚步、拍手、扔石头）会短暂照亮周围。
- 声音也会引来怪物。
- 每一次「看见」都有代价，玩法上是潜行加解谜。
- 美术极简（线框加粒子），氛围靠音效撑起来。

### 7. 候鸟（Flock）

- 你不控制单只鸟，而是用风向、领头鸟和叫声引导一整个鸟群迁徙。
- 途中有暴风、猛禽和城市灯光。
- Boids 群体模拟，画面治愈，适合做成短篇，2–3 小时通关。

### 8. 画天气（Weathercraft）

- 用笔在天空画云、画风，影响下方小镇的农田、风车和帆船。
- 物理沙盒，每关给出「三天后让麦子成熟」这类目标。
- 适合触屏，可以考虑上手机或平板。

## 下一步建议

1. 先从推荐的三个里挑一个，或者把两个点子混合起来（比如「回放小队」加「电梯」）。
2. `cd game-studio && claude`，然后运行 `/start`；如果已经有方向，直接运行
   `/brainstorm 回放小队`。
3. 引擎选好后运行 `/setup-engine godot 4.6`（或你选的引擎）。
4. 先做一个只有核心循环、一关、不带美术的原型（`/prototype`），
   一周内验证「好不好玩」，再决定要不要继续投入。
